Tenant
Campo Tipo de Dato Nulos Restricciones / Claves Descripción

cancha.roles_complejo

Multitenant Access
Campo Tipo de Dato Nulos Restricciones / Claves Descripción
id UUID NOT NULL PRIMARY KEY Identificador único de rol.
complejo_id UUID NOT NULL FK → cancha.complejos(id) Complejo al que pertenece.
usuario_id INTEGER NOT NULL FK → sistema.usuarios(id) Usuario asignado.
rol VARCHAR(30) NOT NULL CHECK (rol IN ('admin_complejo', 'organizador', 'veedor')) Nivel de privilegios del usuario en este predio.

cancha.organizadores 🆕 Migración 009

Lookup Table
Campo Tipo de Dato Nulos Restricciones / Claves Descripción
id INTEGER NOT NULL PRIMARY KEY GENERATED ALWAYS AS IDENTITY Identificador único autoincremental.
usuario_id INTEGER NOT NULL FK → sistema.usuarios(id) UNIQUE Usuario del sistema asignado como organizador.
nombre VARCHAR(200) NOT NULL — Nombre de la organización de torneos o evento.
plan VARCHAR(30) NOT NULL DEFAULT 'basico' Plan contratado (basico, premium, ilimitado).
max_torneos SMALLINT NOT NULL DEFAULT 3 Límite máximo de torneos permitidos en el plan.
habilitado BOOLEAN NOT NULL DEFAULT TRUE Si el organizador está activo.

cancha.torneos

Core Config
Campo Tipo de Dato Nulos Restricciones / Claves Descripción
id UUID NOT NULL PRIMARY KEY Identificador del torneo.
complejo_id UUID NULL FK → cancha.complejos(id) Tenant dueño del torneo (opcional si es organizador libre).
organizador_id 🆕 INTEGER NULL FK → cancha.organizadores(id) Organizador independiente dueño del torneo (opcional si pertenece a un complejo).
modalidad_id SMALLINT NOT NULL FK → cancha.modalidades(id) Modalidad del campeonato (Liga, Eliminatoria, etc).
categoria_id SMALLINT NOT NULL FK → cancha.categorias(id) Categoría de la competencia.
creado_por 🆕 INTEGER NULL FK → sistema.usuarios(id) Organizador que creó el torneo. Permite filtrar "mis torneos" directamente.
nombre VARCHAR(200) NOT NULL — Nombre descriptivo del torneo.
slug VARCHAR(170) NULL UNIQUE Slug de acceso para la landing pública del torneo.
limite_deuda_habilitado 🆕 BOOLEAN NOT NULL DEFAULT FALSE Bloqueo por deuda límite (Mig. 012).
limite_deuda_monto 🆕 NUMERIC NULL DEFAULT 0 Monto límite de bloqueo (Mig. 012).
multa_amarilla_monto 🆕 NUMERIC NULL DEFAULT 0 Monto de multa amarilla (Mig. 012).
multa_roja_monto 🆕 NUMERIC NULL DEFAULT 0 Monto de multa roja (Mig. 012).

cancha.tipos_evento 🆕 Migración 008

Lookup Catalog
Campo Tipo de Dato Nulos Restricciones / Claves Descripción
id SMALLINT NOT NULL PRIMARY KEY GENERATED ALWAYS AS IDENTITY Identificador autoincremental.
codigo VARCHAR(30) NOT NULL UNIQUE Código del tipo. Ej: GOL, AMARILLA, SUSTITUCION.
nombre VARCHAR(100) NOT NULL — Nombre legible del tipo de evento.
aplica_a VARCHAR(20) NOT NULL CHECK IN ('jugador', 'equipo', 'partido') A qué entidad aplica el evento.
afecta_marcador BOOLEAN NOT NULL DEFAULT FALSE Si el evento modifica el score del partido.
afecta_disciplina BOOLEAN NOT NULL DEFAULT FALSE Si el evento puede generar una sanción disciplinaria.

cancha.eventos_partido

Events Log
Campo Tipo de Dato Nulos Restricciones / Claves Descripción
id UUID NOT NULL PRIMARY KEY Identificador del evento.
partido_id UUID NOT NULL FK → cancha.torneos_partidos(id) Partido en el que ocurre.
tipo_evento_id 🆕 SMALLINT NULL FK → cancha.tipos_evento(id) FK al catálogo normalizado de tipos de evento.
player_id UUID NULL FK → cancha.tournament_players(id) Jugador protagonista. En SUSTITUCION: el jugador que entra.
player_out_id 🆕 UUID NULL FK → cancha.tournament_players(id) Solo para SUSTITUCION: jugador que sale del campo.
equipo_id UUID NOT NULL FK → cancha.torneos_equipos(id) Equipo del jugador en ese partido.
tipo VARCHAR(25) NOT NULL — Código del tipo de suceso (GOL, AMARILLA, SUSTITUCION, etc.).
minuto SMALLINT NOT NULL CHECK (0–150) Minuto exacto del evento.
periodo SMALLINT NOT NULL DEFAULT 1 — CHECK IN (1, 2) Primer o segundo tiempo.
