Límites Indeterminados

Concepto y resolución de la forma 0/0.

Comprenderemos y aplicaremos técnicas algebraicas de factorización y simplificación para romper el estancamiento matemático.

2 Horas Cátedra · Análisis y Práctica

Objetivo General

Resolver límites indeterminados de la forma 0/0 en funciones racionales mediante técnicas algebraicas.

0 / 0

Una expresión que pide ser transformada

Matemática3º
01 · Inicio & Desafío

El Conflicto Cognitivo

Ejemplo A
limx→2 (x + 3)
Sustitución: 2 + 3 = 5 (Determinado)
Ejemplo B
limx→2 (x² − 4) / (x − 2)
Sustitución: (4 − 4) / (2 − 2) = 0/0
El Enigma
0 / 0
¿Qué representa esta expresión?

¿Significa que el límite no existe?

No necesariamente. Un resultado de 0/0 nos indica que existe un "estancamiento" y necesitamos usar una estrategia algebraica para encontrar el verdadero valor.

Matemática3º
02 · Definición

¿Qué es una Indeterminación?

Cuando al sustituir la variable por el valor al que tiende obtenemos 0/0, no se puede predecir de antemano el resultado final.

limx→a f(x)/g(x) = 0/0   ⇒   ¡Necesitamos factorizar!
1

Raíz Común

El valor al que tiende la variable es una raíz común del numerador y del denominador.

2

Factorizar

Usaremos casos de factoreo para descomponer los polinomios y hacer visible al causante del cero.

3

Simplificar

Eliminaremos los factores comunes que producen la división por cero.

Matemática3º
03 · Estrategia Algebraica

Herramientas de Factorización

Técnica 1

Diferencia de Cuadrados

Se aplica a binomios donde ambos términos tienen raíz cuadrada exacta.

a² − b² = (a − b)(a + b)

Ejemplo: x² − 4 = (x − 2)(x + 2)

Técnica 2

Trinomios Cuadráticos

Se aplica a expresiones de la forma x² + bx + c buscando dos números que sumados den "b" y multiplicados "c".

x² + bx + c

Ejemplo: x² − 3x + 2 = (x − 2)(x − 1)

Paso Final
  • Simplificar el factor común entre numerador y denominador.
  • Reemplazar nuevamente la variable por el valor de tendencia para hallar el límite final.

04 · Práctica Guiada

Resolución Paso a Paso

Límite Original Factorización y Simplificación Reevaluación
limx→2 (x² − 4) / (x − 2) (x − 2)(x + 2) / (x − 2)  →  Queda: (x + 2) 2 + 2 = 4
limx→2 (x² − 3x + 2) / (x² − 4) (x − 2)(x − 1) / (x − 2)(x + 2)  →  Queda: (x − 1)/(x + 2) 1 / 4
limx→3 (x² − 9) / (x − 3) (x − 3)(x + 3) / (x − 3)  →  Queda: (x + 3) 3 + 3 = 6

06 · Recapitulación

Ideas Clave de la Jornada

1

Verificar la Indeterminación

Si la sustitución directa produce 0/0, la función tiene un factor problemático en común.

2

Descomponer (Factorizar)

Aplicar Diferencia de Cuadrados o Trinomios Cuadráticos para revelar los causantes del cero.

3

Simplificar y Resolver

Se elimina (simplifica) el factor que causa el cero tanto arriba como abajo y luego se vuelve a evaluar el límite.
